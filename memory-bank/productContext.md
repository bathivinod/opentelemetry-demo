# Product Context: OpenTelemetry Demo

## Why This Project Exists
To provide a comprehensive, realistic, and extensible demo environment for OpenTelemetry, enabling users to understand, test, and showcase observability best practices in distributed systems.

## Problems Solved
- Lack of realistic, multi-language demo environments for observability
- Difficulty in demonstrating and testing OpenTelemetry integrations
- Need for a reference implementation for OpenTelemetry contributors and vendors

## User Experience Goals
- Easy to deploy and use (via Docker/Kubernetes)
- Clear documentation and onboarding
- Realistic e-commerce scenario (Astronomy Shop)
- Demonstrates end-to-end observability and troubleshooting
